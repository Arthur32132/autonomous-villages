Oracle findings: 26.2 separates BlockTags.GRASS_BLOCKS from DIRT; explicitly include both for natural terrain. Multi-block bed/door writes require known-shape flags for the pair before neighbor updates. Vanilla item drops have pickup delay: keep workers collecting for 80 ticks. The native eight-slot food inventory may capture wheat/seeds before the backpack: move those ingredients transactionally to the working backpack. Furnace checks intentionally reject remote servicing; the probe now walks both to insert input and collect output instead of asserting a remote transfer. Initial fixture failures and fixes are recorded here; later server logs live under build/validation. Probe moved into a separate validation JAR so shipped bytes can be tested unchanged.

2026-10-14 real-server route diagnosis: workers could repeatedly reach a stand position that was still outside the action's stricter reach. This produced a 1000-tick loop despite successful pathfinding. Stand selection now uses the actual interaction radius, a 0.65-block movement tolerance, and line of sight, rather than a fixed unrelated distance. Top-down forestry uses the larger block interaction range. This fixes both mining and occasional crop approach failures.

Empty-inventory oracle: farming must not starve first wood/workbench/depot creation. Forestry now removes the trunk from the bottom upward so drops fall to accessible ground; previously cut trunks are recorded by position for restart recovery. Adult villagers can stand on farmland (15/16 collision height), which is not a full sturdy face. House placement uses worker eye reach and paid adjacent block assembly, rather than requiring a center ray through an already built roof edge. The final house has 85 steps, including an entrance stair, and consumes 80 structural planks plus the door, stair, beds and torch.

Final corrections: ground-level collection positions avoid chasing falling drops into tree canopies. Unreachable trunks receive a retry delay without monopolizing food jobs. New storage and furnace references are saved immediately. Furnace output insertion uses a disposable backpack copy so a rejected partial insertion cannot duplicate ingots when fuel transfer succeeds in the same transaction. The regression probe exercises a nearly full backpack with simultaneous fuel insertion. The bootstrap fixture waits for both native entities to be tracked before claiming, avoiding a test-only spawn/tracking race.
