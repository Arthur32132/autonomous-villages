# Autonomous Villages 0.1.1

Отдельный мод для Minecraft Java **26.2 / Fabric**, превращающий выбранную деревню в управляемое хозяйство. Жители остаются настоящими `Villager`: сохраняют UUID, внешность, профессию, торговлю, возраст и обычные правила смерти. Навигация, добыча и бой выполняются библиотекой Navigation AI.

## Запуск

Нужны Java 25, Fabric Loader 0.19.5 и Fabric API 0.161.0+26.2. Скопируйте в `mods` два JAR из этого комплекта: `autonomous-villages-0.1.1.jar` и **приложенный** `navigation-ai-0.1.1.jar`. При обновлении уберите предыдущие версии этих двух модов из `mods`. AutonomousBots не требуется.

Версия 0.1.1 исправляет падение при создании/загрузке одиночного мира: библиотека теперь загружается также на клиенте для встроенного сервера. Мод требует исправленную библиотеку версии 0.1.1 или новее; API и формат сохранений совместимы с предыдущей версией.

В одиночной игре установите их в Fabric-профиль. На выделенном сервере достаточно установки на сервер. Для команд нужны права оператора уровня 2 / включённые читы.

Встаньте в деревне и выполните:

```mcfunction
/avillage claim "Берёзовка"
/avillage status "Берёзовка"
```

Команда находит кровати в пределах 64 блоков, выбирает ближайшую группу и вычисляет центр. По умолчанию управляется круг радиусом **48 блоков** вокруг этого центра, с высотой до 48 блоков вверх/вниз. Необходимы хотя бы одна кровать и один живой житель. Территория включает имеющиеся в ней фермы и природные ресурсы. Для большого поселения укажите радиус до 64:

```mcfunction
/avillage claim "Берёзовка" 64
```

Проверьте центр и радиус через `status`. Если выбрана неподходящая область, освободите деревню и выберите её заново с другой позиции/радиусом.

## Управление

| Команда | Действие |
|---|---|
| `/avillage claim <имя> [24..64]` | Выбрать деревню и запустить автономность |
| `/avillage status [имя]` | Территория, работники, кровати, склад, запасы еды и текущие занятия |
| `/avillage storage <имя> <x y z>` | Разрешить использовать конкретный незапертый сундук внутри территории; игрок должен быть не дальше 8 блоков |
| `/avillage pause <имя>` | Остановить работы и снять билеты загрузки; рюкзаки сохраняются, обычный ИИ жителей работает |
| `/avillage resume <имя>` | Возобновить работу и загрузку территории |
| `/avillage release <имя>` | Удалить управление деревней; оставить жителей и постройки. Вещи рабочего рюкзака возвращаются дропом, предмет в руке остаётся |

Имена — до 32 букв/цифр/`_`/`-`, без пробелов; кириллицу заключайте в двойные кавычки. Одновременно разрешены 4 непересекающиеся территории, до 64 зарегистрированных жителей на каждую. Консоль может использовать `execute positioned ... run avillage claim ...`.

## Что делает деревня

- Работники сами выбирают нужные задачи. Общий запас учитывает содержимое реальных складских сундуков и рабочих рюкзаков. Цели работы резервируются, чтобы два жителя не собирали один блок одновременно.
- Древесина заготавливается с естественных стволов на земле с листвой. Блоки домов для этого не выбираются. Подобранные саженцы высаживаются по окраинам, без ускоренного роста.
- Созревшие посевы собираются с настоящим дропом и пересеваются семенами. Подходящая земля возле воды обрабатывается настоящей мотыгой. Поддерживаются пшеница, морковь, картофель и свёкла. При отсутствии семян жители ищут их в траве.
- Жители добывают доступный камень/уголь/железо и при необходимости прокладывают ограниченную лестничную шахту с возвратом к входу. Инструменты изнашиваются. Добыча не создаёт руду или ресурсы из воздуха.
- Рецепты проверяются загруженным Minecraft recipe manager. Из материалов делаются доски, палки, рабочие блоки, инструменты, оружие, щиты, железная броня, хлеб, факелы, ножницы и кровати. Рецепты больших размеров требуют находящегося рядом верстака. `limitedCrafting` отключает крафт жителей, поскольку у них нет книги рецептов игрока.
- Железо и древесный уголь получаются в настоящей печи, с обычным топливом и временем плавки. Мод обслуживает только созданные им печи. Чужие печи не присваиваются.
- Работник физически подходит к складу и переносит предметы. Обычные найденные сундуки не используются, пока игрок явно не разрешит их командой. Если склада ещё нет или он заполнен, заведующий изготовит и поставит новый сундук из добытых материалов; предел — 16 складских сундуков.
- Еда переносится в обычный восьмислотовый инвентарь жителей. У жителей нет голода игрока; еда служит обычному обмену и размножению. Днём предусмотрены отдельные часы работы у родного профессионального блока для обновления сделок и время общения, ночью работы прекращаются и жители возвращаются к обычному сну. Дети растут по правилам Minecraft и не работают.
- При нехватке кроватей заведующий строит простой дом 5×5: пол, стены, крыша, входная ступень, деревянная дверь, две кровати и факел. Постройка оплачивается материалами, не заменяет существующие здания и может возобновиться после перезапуска. Создаётся запас до двух свободных кроватей, целевой предел строительства — 24 кровати, максимум восемь новых домов.
- Вооружённые здоровые жители защищаются от монстров; слабые отступают, от криперов стараются уйти. Это не бессмертная армия: жители могут погибнуть, рейды остаются опасными. Мод не создаёт замену погибшим и не заставляет рождаться детей.

Пока деревня активна, сервер держит её область загруженной и симулируемой: ходят жители, растут растения и работают печи даже без игроков рядом. Мод предотвращает автоматическую паузу пустого выделенного сервера, пока есть активные деревни; `server.properties` не изменяется. После приостановки/освобождения последней деревни обычная автопауза возвращается. Выключение сервера и пауза одиночной игры останавливают время. Пауза/освобождение снимают билеты загрузки. Билеты принадлежат отдельному типу мода и не записываются как постоянные `/forceload`.

## Условия автономности

Нужны доступные исходные ресурсы: деревья или древесина, семена/посевы, вода, камень и место для работ. Для дополнительных кроватей нужны шерсть и доступные овцы либо шерсть на общем складе. Жители не телепортируют ресурсы с другой стороны мира. На острове без деревьев или в деревне без семян замкнутый цикл не возникнет сам по себе; `status` сообщает основные нехватки. Запасы можно дать через разрешённый склад.

Это хозяйственная автономность в ограниченной территории. В текущей версии нет торговли с игроками по собственной инициативе, караванов между деревнями, сложной архитектуры, осушения/терраформирования площадок, порталов и планирования победы в рейдах. Шахта ограничена 32 ступенями; истощение доступных минералов потребует дополнительных запасов. Профессиональные сделки, репутация и размножение работают через обычный ИИ Minecraft.

## Сохранения и сборка

Метаданные находятся в корне мира в `autonomous_villages.json`; рюкзаки сохраняются библиотекой в NBT настоящих жителей. Предметы не дублируются в JSON. Запись метаданных идёт через временный файл и атомарную замену. Повреждённый JSON не перезаписывается, управление приостанавливается с сообщением в журнале.

```powershell
./gradlew.bat test build bundleDistribution
```

Сборка ожидает соседний проект `../MinecraftmodNavigationAi` с готовой библиотекой. `build/autonomous-villages-0.1.1-bundle.zip` содержит оба мода и инструкции. Команда `validationJar` собирает отдельный проверочный мод; `python tools/validation/run.py` запускает его в новом мире на `127.0.0.1:25589`, используя только бинарные файлы и уже принятую EULA тестового шаблона. `clientValidationJar` и `python tools/client-validation/run.py` проверяют создание и повторную загрузку мира настоящим клиентом в отдельном профиле. Проверочные JAR не входят в комплект.
