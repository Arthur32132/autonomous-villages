# Security

This is an experimental project with no supported stable release or promised
security response time. Use the latest source when preparing a report and state
the exact commit, Minecraft/Fabric versions and relevant configuration.

For exploitable vulnerabilities, exposed credentials or private player data,
use GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/Arthur32132/autonomous-villages/security/advisories/new).
Do not disclose the exploit, secrets or personal data in a public issue or PR.
Include reproduction steps and impact using a disposable world and redacted
evidence. Ordinary gameplay bugs belong in public issues.
