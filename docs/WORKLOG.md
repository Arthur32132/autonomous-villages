### Навигация — главный тормоз всего мода (и 0.2.2 тоже)
- Диагностика в зонде: по каждому жителю задача, статус навигатора, позиция; метрики
  navigation-ai (снимки, поиски, очередь) в таймлайне; `digest.py --workers`.
- Жители почти всё время в `COMPUTING`. Причины:
  1. soak на 400 TPS: бюджет планирования = доля реального времени тика (0,2–0,5 мс против
     5 мс на 20 TPS) → soak переведён на 100 TPS (`--tick-rate`, README);
  2. поиск пути в среднем **1027 мс** (JFR): хеш `GridPos` по умолчанию вырождал HashMap
     в деревья (36% времени), прыжки до 4 блоков проверялись по ровной земле (~40%),
     Парето-метки (стоимость, шаги) раздували A*.
- navigation-ai PR [#1](https://github.com/Arthur32132/navigation-ai/pull/1) смёржен:
  нормальный хеш, прыжок только через яму/препятствие, метки по стоимости, плотные массивы
  в снимке. Поиск **1027 → 60–80 мс**, снимок 50 → 23–32 мс, маршрутов за тик вдвое больше,
  потоки поиска тратят в 6 раз меньше CPU. 115 тестов библиотеки зелёные.
- Phase 0 PR [#3](https://github.com/Arthur32132/autonomous-villages/pull/3) смёржен.
- Baseline 0.2.2 (400 TPS, 3 дня): normal — из 31 жителя выжили 5 (26 смертей), peaceful —
