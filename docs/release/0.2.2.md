# Кандидат 0.2.2 — 17 октября 2026

Minecraft Java 26.2, Fabric Loader 0.19.5, Fabric API 0.161.0+26.2, Java 25.
Устанавливаются оба основных JAR из одного комплекта:

- `autonomous-villages-0.2.2.jar`;
- `navigation-ai-0.2.2.jar`.

Старые версии этих двух модов следует убрать из папки `mods`. Fabric API
устанавливается отдельно. Для одиночной игры нужен Fabric-профиль; на выделенном
сервере моды устанавливаются на сервер. Перед обновлением своего мира сохраните
его резервную копию. Отдельные проверочные моды для установки не нужны.

## Состав комплекта

`build/autonomous-villages-0.2.2-bundle.zip` содержит два JAR, исходники обоих
проектов, README, CHANGELOG, VALIDATION, статический аудит, roadmap и
`build-manifest.json` с SHA-256 JAR и исходных файлов. Minecraft, библиотеки
игры, пользовательские миры, профили и тестовые лаборатории не включаются.

Исходные репозитории: [Autonomous Villages](https://github.com/Arthur32132/autonomous-villages)
и [Navigation AI](https://github.com/Arthur32132/navigation-ai).

## Воспроизведение упаковки

Из каталога AutonomousVillages, рядом с исходниками MinecraftmodNavigationAi:

```powershell
./gradlew.bat bundleDistribution -x test -x :navigationAi:test --offline --no-daemon
./gradlew.bat --stop
```

Offline-сборка требует уже загруженных зависимостей. Сборка проверяет компиляцию
и создаёт артефакты; она не запускает Minecraft и не проверяет игровой цикл.
