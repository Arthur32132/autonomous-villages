# Исправления ревью — Autonomous Villages 0.2.1

Комплект предназначен для Minecraft Java 26.2, Fabric Loader 0.19.5, Fabric API 0.161.0+26.2 и Java 25.

| Находка | Исправление |
|---|---|
| Накопление метаданных ломает загрузку | Ограниченная история рабочих участков с сохранением активных ссылок; ограничения при создании новых работ; очистка исторических счетчиков; валидация перед атомарной записью. Предметы не удаляются. |
| Крыльцо выходит за границу | Проверяется вся площадка с отрицательным отступом и верхними деталями; известный старый вынос до четырех блоков восстанавливается при загрузке. |
| Очередь разгрузки | Участникам выделяются разные внешние места ожидания. Носильщик не мешает помощнику выйти из прохода. Исчерпанные подходы повторно проверяются после ограниченной задержки. |
| Неполный сундук блокирует перенос | Переносит ровно вместившуюся часть партии, списывая только принятые предметы. |
| Выгруженный участник считается погибшим | Временная недоступность не удаляет участника из экспедиции; смерть определяется членством поселения. |
| Release оставляет старый контроллер | Отложенное освобождение хранится в JSON v3; при загрузке жителя отменяется управление, возвращается рюкзак и восстанавливается имя. Старые JSON v1/v2 поддерживаются. |
| Готовность игнорирует геометрию | Сравниваются конструктивные свойства направления, половины, типа плиты, оси, части кровати, петли и поворота. Открывание дверей остается обычным состоянием Minecraft. |
| Двойная плита за одну | Требует и расходует две настоящие плиты. |
| Разрушение чужого поселения | Общая защита всех управляемых деревень, включая паузу, верхние половины дверей и изголовья кроватей. |

Жилье завершается до начала новых необязательных улучшений. Территория ограничена бюджетом 1024 базовых чанков на поселение: чрезмерная старая территория приостанавливается, не удаляется. Этот предел не является обещанием производительности при 1024 жителях; проверка масштабирования относится только к фактически испытанным сценам.

Сборка использует Gradle project dependency на соседний MinecraftmodNavigationAi; библиотека собирается автоматически из исходников. Номер версии обоих модов — 0.2.1. Манифест комплекта перечисляет SHA-256 JAR и исходников. Проверочные моды, игровые миры, библиотеки Minecraft и кэши в комплект не входят.

Фактические результаты кандидата приведены в VALIDATION.md. Исторические 75 PASS и FAIL длительного прогона 0.2.0 не переносятся на 0.2.1.

Длительный тест первого кандидата выявил дополнительные ошибки. Общие цели (дом, сундук, верстак, безопасная точка) больше не получают эксклюзивную блокировку на весь путь. Для сна выбирается целый дом; при повреждении двери/стен житель просыпается и ищет другое укрытие. Неудачный подход к занятой кровати у поверхности ночью не запускает раскопку пути наружу. Во временном альтернативном доме сохраняется управление, чтобы обычный Brain не увёл жителя обратно в повреждённую комнату.

Экспедиция за шерстью завершает текущую атомарную работу и подбор дропа перед плановым возвращением. Успех требует фактически собранной новой шерсти; учитывается её обычный подбор и расход на кровати. Динамическое соединение сундуков не считается разрушением чертежа. Наблюдатель фиксирует успешное окончание настоящей добычи через границу расписания по времени задачи; в Normal-тесте часы не переставляются.
