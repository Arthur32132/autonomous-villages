# Полный сценарий при 400 TPS — FAIL до достижения лимита

16 октября 2026. Один запуск неизменного кандидата в одноразовом клиентском мире.

Команда: `python tools/client-validation/run.py --colony --growth --live-threats --tick-rate 400 --max-ticks 144000`.

Цель — 144000 тиков, Normal, естественные ночь/погода/угрозы, без пожертвованных предметов и производственных заготовок. Штатные критерии не изменены.

Сценарий остановился на **38765-м тике** с `resident_lost_during_live_observation`: строитель `1fb50a30-4ae0-4bff-8f4a-eef2ad488da1` убит зомби в точке (-320.70, 71.00, -321.25), пытаясь укрыться от угрозы. Журнал сервера подтверждает причину смерти. Связь гибели с ускорением не установлена. Полные 144000 тиков не выполнены, автономная приёмка не пройдена.

Последний снимок на 38600-м тике: склад 21/161 блок, новых домов 0, подтверждённых новых шахтёрских доставок 0; сон ночью наблюдался. Последнее измерение — 399.901 TPS, среднее — 384.046 TPS, средняя стоимость тика — 1.196 мс. Эти показатели скорости не означают успешной автономности.

Сборка игровых JAR и проверочного JAR подтверждена Java 25; исходники во время наблюдения не менялись. Клиент завершился с кодом 0, запускатель — с кодом 1 по результату сценария. Повторных игровых запусков не было. Java-процессов после теста нет, временная лаборатория удалена; оригинальный профиль не изменялся.

Исходные компактные артефакты: `build/validation-reports/client-20261016-182434-329043` (подлежат ротации). Постоянная выжимка с SHA-256 JAR: [results.json](results.json).
