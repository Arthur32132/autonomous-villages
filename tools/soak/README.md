# Headless soak (Linux / cloud sessions)

Один прогон = одноразовый мир на выделенном Fabric-сервере 26.2:

1. зонд `SoakProbe` (отдельный JAR `autonomous-villages-soak`, игрокам не поставляется) ищет
   ближайшую сгенерированную деревню по сиду, загружает её тикетом и ставит над ней
   креативного летающего наблюдателя (бот `SoakCam` из Navigation AI): без игрока рядом ванилла
   не спавнит мобов, а с ним — спавн как в обычной игре;
2. на 20 TPS ждёт загрузки жителей, делает `claim` и переключает сервер на `--tick-rate`;
3. каждые 1200 тиков пишет строку в `soak-timeline.jsonl`, каждые 6000 — перепись блоков и сундуков;
4. через `--days` игровых дней пишет `soak-result.json` и останавливает сервер.

```sh
python3 tools/soak/run.py --days 3 --seeds 8675309,42,1337 --difficulty peaceful,normal --parallel 2
python3 tools/soak/run.py --days 3 --seeds 42 --no-claim      # контроль: деревня без мода
python3 tools/soak/run.py --prepare-only                       # только скачать/подготовить сервер
```

Нужен JDK 25 (`AV_JAVA_HOME`, `~/jdk/jdk-25*` или `JAVA_HOME`). Шаблон сервера кешируется в
`~/.cache/av-soak/template` (`AV_SOAK_TEMPLATE`), лаборатории — `build/soak-labs` (удаляются после
прогона, `--keep-lab` оставляет), отчёты — `build/soak-reports/<batch>/<seed>-<difficulty>/`
плюс `summary.json` всей партии.

## Метрики

Метрики наблюдаются в мире и не зависят от реализации мода:

| Поле | Смысл |
|---|---|
| `outcome.births` | новорождённые жители в зоне (возраст ≤ −23000 при первом появлении) |
| `outcome.deaths` | смерти жителей зоны; причины и убийцы — в `deaths` |
| `outcome.newBeds` | прирост POI `home` (кроватей) в зоне |
| `outcome.builtBlocks` | сумма положительных приростов «рукотворных» блоков: доски, булыжник, двери, свет, сундуки, верстаки, печи, заборы, ступени, плиты, стекло, тропинки, кровати, шерсть, колокола |
| `outcome.logsChange` | изменение числа брёвен (вырубка < 0) |
| `outcome.farmlandChange` | изменение пашни |
| `idleByJob` | сколько раз взрослый неспящий житель простоял на месте весь интервал, по текущей работе |
| `avgTps` | реальная скорость прогона |
| `modFinal`, `modStatus` | внутренний взгляд мода (единственная часть, зависящая от реализации) |

`outcome.score = 10·newBeds + 20·births + builtBlocks/10 − 25·deaths` — одно число для сравнения
партий; решения принимаются по полям, а не только по нему.

Зона — прямоугольник ±`--radius` (112) вокруг структуры деревни, объединённый с границами
поселения мода +16 блоков. Перепись блоков берёт 25 верхних слоёв каждой колонны.
